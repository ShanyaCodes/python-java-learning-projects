## Python：基于颜色直方图的图片相似检索
环境：Python 3.10以上。进入 Python图片检索 文件夹后运行：

    python -m pip install -r requirements.txt
    python image_search.py --query 查询图片.jpg --folder 图片库 --top 5

把命令中的路径替换为自己的文件路径，路径含空格时用双引号包住。结果输出到 results.csv。

增加的难度：图像特征提取、向量归一化、余弦相似度、Top-K排序、损坏图片容错、CSV输出。只依赖Pillow，不需要GPU。
先读懂 feature，再读 search，最后读命令行入口。准备10至20张自己的图片，观察颜色相近但内容不同的误检。相似度不是准确率，也不是模型识别置信度。
第一项自己的修改：添加按文件名筛选；第二项：增加灰度特征并对比结果；第三项：做一个简单预览界面。
自查：相同图片得分是否接近1；颜色不同的图片如何排序；查询图是否排除；损坏图片能否跳过。
局限：这是传统图像检索基线，不是目标检测、深度学习或无人机控制，也没有训练过程。可用于熟悉图像数据与排序思路。

## Java：实验设备预约管理
环境：JDK 8以上。进入 Java设备预约 文件夹后运行：

    javac -encoding UTF-8 BookingApp.java
    java BookingApp

按菜单新增、查看和取消预约。时间格式为2026-11-06T09:00。数据保存在当前目录 bookings.tsv，重启后保留。取消时输入完整编号。
验证核心逻辑：

    java BookingApp --self-test

增加的难度：LocalDateTime时间处理、预约冲突判断、集合与排序、UUID、持久化及异常处理。相邻预约允许首尾相接。
先读 Booking 类和 overlaps，再读 load/save，最后读菜单。
第一项自己的修改：按设备筛选；第二项：阻止预约过去时间；第三项：改用MySQL，并使用参数化查询；后续再考虑Spring Boot接口。
局限：单用户本地教学程序，没有登录权限、多进程并发保护或生产级事务；不要写成已实现这些功能。
